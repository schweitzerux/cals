# Cals

A week-to-week calorie tracker for the phone. Log calories through the day, weigh in once a week, and see calories in against calories out.

- Type `1250 panda plate` to add an entry. Labels become saved items that appear as you type.
- Weeks run Monday to Sunday.
- Calories out starts from a number you enter, then adjusts slowly using your log and weekly weigh-ins.
- There are no goals, target weights or streaks.

All data stays in the browser on your device. Nothing is sent anywhere, and backups are files you save yourself. Personal data never belongs in this repo: `private/` is ignored by Git.

Open the site in Chrome on Android and choose Install app or Add to Home screen from the menu. On an iPhone, use Safari and choose Share, then Add to Home Screen. Tests: `npm test`.
